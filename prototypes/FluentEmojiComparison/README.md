# Fluent Emoji 3D — отдельный прототип сравнения

Самостоятельное WPF-окно .NET 10 / Windows x64. Проект не ссылается на MED и не
содержит его стартап, трей, Win+., вставку, настройки или пользовательскую историю.
Единственная NuGet-ссылка — уже используемая в MED Emoji.Wpf 0.3.4 для системного
варианта. Новых библиотек/версий для этого прототипа не требуется.

## Просмотр

Запустите `bin/Release/net10.0-windows/win-x64/FluentEmojiComparison.exe`.
Для переноса сохраняйте всю папку self-contained сборки.

- Размеры **64/96/128 px** показаны одновременно в соседних колонках. Все варианты
  отображаются в одинаковом размере; большой исходный файл не получает большую
  область показа.
- Выпадающий список **«Моделирование DPI»** переключает **100/125/150%**: образец
  занимает соответственно **32/40/48 физических пикселей**, то есть 32 DIP при
  выбранном моделируемом DPI. Фактический DPI окна компенсируется, чтобы не
  умножать выбранный масштаб повторно на системный. Это имитация размера образцов,
  а не изменение DPI Windows или масштаба интерфейса MED.
- **«Фон образцов»**: оба рядом, светлый или тёмный. По умолчанию видны оба фона.
- Первая колонка изображений использует тот же рендерер Emoji.Wpf / Segoe UI Emoji,
  что MED. Доступность/вид системного варианта зависит от установленного шрифта и
  возможностей библиотеки, особенно для skin-tone/ZWJ/flag-последовательностей.
- Прокрутка позволяет просмотреть все 15 строк. Размер каждого PNG подписан под
  образцами. Исходный относительный путь виден в подсказке названия эмодзи.

## Подготовленные изображения

15 Unicode-последовательностей, включая обязательные 10 и дополнительные сложные:
👩🏽‍💻, 🧑🏾‍🚀, 👨‍🚒, 👩‍🦼, 🏳️‍🌈. Для каждого подготовлено три PNG, всего **45**.
Оригинальные 3D PNG Microsoft выбираются по точным metadata.unicode/unicodeSkintones.
Имена картинок основаны на кодовых точках; FE0F, ZWJ и модификаторы не удаляются.

Уменьшение — separable antialiased Lanczos3, линейное цветовое пространство,
premultiplied alpha во время фильтрации, затем PNG со straight alpha. Пропорции
сохраняются; подложка, контраст, насыщенность и дополнительное повышение резкости
не применяются. Исходные PNG не перезаписываются. `Assets/samples.json` содержит
пути/хеши оригиналов, размеры, байты и SHA-256 всех производных PNG.

Размеры подготовленного набора (без manifest, лицензий и .NET runtime):

| Разрешение | PNG | Байт |
| --- | ---: | ---: |
| 64×64 | 15 | 106 203 |
| 96×96 | 15 | 186 188 |
| 128×128 | 15 | 281 141 |
| Всего | 45 | 573 532 |

Это ресурсы именно 15 образцов, не оценка полного каталога. Визуальное качество
предстоит оценить вручную. Предварительный компромисс — 96 px; при моделируемых
100–150% даже 64 px превышают физический размер показа 32–48 px, поэтому выбирать
окончательный вариант следует по сравнению, а не по одному размеру файла.

Генерация выполняется отдельно, не при обычном запуске:

```powershell
dotnet build prototypes/FluentEmojiComparison/FluentEmojiComparison.csproj -c Release -r win-x64 --self-contained true
Start-Process -FilePath ./prototypes/FluentEmojiComparison/bin/Release/net10.0-windows/win-x64/FluentEmojiComparison.exe -ArgumentList '--prepare','C:/Projects/MED/external/fluentui-emoji-main','C:/Projects/MED/prototypes/FluentEmojiComparison' -Wait -WindowStyle Hidden
dotnet build prototypes/FluentEmojiComparison/FluentEmojiComparison.csproj -c Release -r win-x64 --self-contained true
```

Первый build нужен только для запуска генератора, второй встраивает полученные
ресурсы. Изменять всю коллекцию или добавлять её в csproj не нужно.

## Самопроверка без показа окна

```powershell
Start-Process -FilePath ./prototypes/FluentEmojiComparison/bin/Release/net10.0-windows/win-x64/FluentEmojiComparison.exe -ArgumentList '--verify','C:/Projects/MED/prototypes/FluentEmojiComparison/obj/verification.json' -Wait -WindowStyle Hidden
```

Проверяются хеши/декодирование 45 embedded PNG, размеры, прозрачность, наличие всех
120 light/dark/system ImageSource, одинаковый размер отображения, переключение
фона и математическая компенсация DPI. Окно не показывается. Проверки не заменяют
субъективное сравнение контуров/деталей на настоящем мониторе.
