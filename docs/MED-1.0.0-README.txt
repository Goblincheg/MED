MED 1.0.0 — Mikhalych Emoji Dock (Мёд)
Windows 10 x64 / .NET 10 self-contained

PORTABLE
1. Распакуй всю папку ZIP в доступный для записи каталог.
2. Закрой предыдущую копию Classic Emoji Picker или MED через её меню выхода.
3. Запусти MED.exe. MED работает в фоне без постоянного значка в трее.
4. Открой панель через Win + .; шестерёнка открывает настройки.
Автозагрузка portable по умолчанию выключена. portable.txt должен оставаться рядом
с MED.exe. Настройки, история и журналы находятся в Data рядом с приложением.
Не запускай MED непосредственно из ZIP.

УСТАНОВКА (если Setup EXE подготовлен)
Запусти MED-1.0.0-win-x64-setup.exe. Установка выполняется для текущего пользователя
в %LOCALAPPDATA%\Programs\MED, без обязательного UAC и без установки runtime.
Автозагрузка включена по умолчанию; её можно отключить в установщике/настройках.
Ярлыки MED и MED — настройки создаются в меню «Пуск», на рабочем столе — нет.
Настройки и история установленной версии находятся в %APPDATA%\MED.
Удаление через список установленных приложений убирает файлы и принадлежащую этой
установке запись автозапуска, сохраняя пользовательские данные.

УПРАВЛЕНИЕ
Win + . — открыть/закрыть панель. Esc или клик снаружи — закрыть панель.
Вводи запрос на русском или английском. Выбирай эмодзи мышью или клавиатурой;
панель остаётся открытой для повторной вставки. История сохраняется автоматически.
Шестерёнка: показ значка в трее, автозагрузка, диагностика, каталог данных, выход.
«Выход из MED» завершает процесс и освобождает Win + . для штатной панели Windows.
MED.exe --settings открывает настройки запущенного MED (или запускает MED с ними).
MED.exe --background запускает в фоне, не открывая панель даже при повторном запуске.

ДАННЫЕ И ПЕРЕНОС
Настройки и история ClassicEmojiPicker копируются при первом запуске, только если
соответствующий файл MED ещё отсутствует. Оригинальные данные не удаляются.
Старую автозагрузку Classic Emoji Picker отключи в его меню перед переходом на MED:
MED не удаляет чужие записи автозагрузки и не запускает два конкурирующих hook.
У portable с недоступным Data используется отдельный резервный каталог AppData,
с явным предупреждением и точным путём в настройках. Он остаётся основным и после
возврата прав записи, чтобы не заменить новую историю устаревшей локальной копией.
Перед переносом закрой MED, скопируй данные из указанного каталога в Data нового
расположения. Для возврата к локальному Data на прежнем месте переименуй файл
portable-fallback.txt в резервном каталоге ПОСЛЕ копирования данных.
Перед переносом/удалением portable отключи его автозагрузку в настройках. Если путь
уже изменился, запусти новую копию и включи автозагрузку заново для обновления пути,
либо нажми «Удалить запись автозагрузки MED». Это управляет только значением MED
в HKCU\Software\Microsoft\Windows\CurrentVersion\Run и не требует администратора.
После входа в Windows приложение стартует без панели; открой её через Win + .

ОГРАНИЧЕНИЯ
При экстремально быстрой вставке возможно предупреждение о неподтверждённом
получателе; защита сохранена. Вставка в повышенное приложение может быть запрещена.
1545 Fluent Emoji 3D отображаются в панели, 7 изображений используют системный
fallback. Шесть нестандартных ninja-cat остаются скрыты. Внешнее приложение само
определяет, какие Unicode-последовательности способен отобразить его шрифт.
При предупреждении скрытый значок может временно появиться для уведомления.
Сборки не подписаны цифровой подписью. Установка/удаление и реальная автозагрузка
требуют ручной проверки; наличие инструкции не означает, что эти действия выполнены.
